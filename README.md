Features
📥 Excel-based data ingestion
🧾 Rate card structuring logic
🖥️ UI rendering of processed data
🔌 Backend API integration via Express

🛠️ Installation & Setup
1. Clone the repository
git clone https://github.com/PARTH-THAPS/RATE-CARD-UI-Onboarding.git
cd RATE-CARD-UI-Onboarding
2. Install dependencies
npm install
3. Run the application
node server.js


How It Works
Excel files are uploaded or loaded into the system
Backend parses .xlsx data into JSON structures
You can create .xlsx file adding data into the form. 


🎯 Use Cases
Internal rate card configuration tools
Pricing onboarding workflows
Data transformation pipelines for Excel-based systems
Admin dashboards for structured pricing data
